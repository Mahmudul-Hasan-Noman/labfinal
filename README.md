# Quizzical

A Flutter quiz application with a polished mobile UI, Open Trivia DB API and Firebase result storage.

## Features

- Splash and welcome screens
- Category selection
- Quiz configuration
- 1 to 50 questions
- Difficulty selection
- Multiple-choice questions
- Live progress bar
- Correct and incorrect answer states
- Result summary
- Firebase anonymous authentication
- Firestore quiz result storage
- Open Trivia DB API integration

## Run

```bash
flutter pub get
dart pub global activate flutterfire_cli
flutterfire configure
flutter run
```

Enable Anonymous Authentication and Firestore in Firebase Console.
